Access the complete dataset and analysis tools from the Greenland Soil Microbiome Project

Data Access Information

Metagenome, 16S rDNA sequencing, assembly, and MAG data have been deposited at the ENA database (PRJEB88872) and the China National GeneBank DataBase (CNP0007079). All data and codes are publicly available as of the date of publication.

Metagenomic Sequencing Data
~10.4 Tbp

Raw metagenomic sequencing data from 283 active-layer soil samples across 64 Greenland sites.

ENA CNGBdb
Assembly Data
~125 GB

Metagenomic assembly data including contigs and scaffolds from the sequencing data.

ENA CNGBdb
16S rRNA Sequencing Data
83.8 million

16S rRNA gene amplicon sequencing data for microbial community structure analysis.

ENA CNGBdb
Metagenome-Assembled Genomes
5,307 MAGs

High- and medium-quality metagenome-assembled genomes from Greenland soil samples.

Browse MAGs CNGBdb
Viral Genomes
3,130 genomes

Viral genomes identified through large-scale virome profiling and virus-host linkages.

Browse Viruses Zenodo
Non-redundant Genes
468 million genes

Comprehensive gene catalog representing the functional potential of Greenland soil microbiomes.

Browse Genes CNGBdb

Developed Tools
  • pctax : Microbial taxonomy analysis
  • MetaNet : Multi-omics network analysis
  • ReporterScore : Functional enrichment analysis
  • iCRISPR : CRISPR system analysis
  • BGCkit : Biosynthetic gene cluster analysis
